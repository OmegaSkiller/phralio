# Practice content

`practice.txt`, `practice.md` and `practice.epub` are the existing bundled parser
examples. They remain English source documents, like a user's imported content;
the surrounding onboarding UI and inline lessons are localized.

`landscape.png` is an original 640 × 360 procedural illustration made for the
image-duration lesson. It depicts a sun and layered mountain ridges, contains
no external imagery and requires no download. It is never decoration behind
an active reading word.

The onboarding never saves these samples to the user's library.
