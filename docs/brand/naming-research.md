# Product naming research

Research date: 25 September 2026. Status: preliminary product naming decision.

## Decision: Phralio

Pronunciation: **FRAH-lee-oh**. Repository slugs: `phralio` and `phralio-pro`.
An invented, seven-letter name suggesting *phrase* and *folio*: language and a
place for reading, rather than a promise of extreme speed. It accommodates RSVP,
ordinary document reading, reflow and future comprehension tools. The rounded
ending gives the otherwise precise consonants a calm voice. The main compromise
is that a listener may spell the first sound with F; use a written wordmark and
pronunciation in launch material. Do not abbreviate the brand to an acronym.

No material conflicting reading or software product use was found in the public
sources reviewed on 25 September 2026. This is **preliminary research, not formal
legal clearance or legal advice**. It does not establish exclusive rights,
registration, worldwide non-use, or domain purchase availability. Formal
trademark clearance should be performed before major commercial investment.

## Sources, queries and coverage

The evidence folder records public API responses, query URLs, dates and compact
web-result excerpts. General Google searches were submitted for the first ten
names as exact name and exact name plus `app`, `software`, `reader`, `reading`,
and `site:play.google.com/store/apps`. The second round received exact-name
searches and the finalist received those additional searches. Several SE Ranking
jobs remained pending and are labelled **not retrieved**; submission is not a
completed search. Rejected names did not receive exhaustive trademark/domain
clearance once a material conflict or product-quality reason was established.

Google sometimes silently substituted words despite quotation marks. Those
results are **not proof of absence**. Direct browser checks with `tbs=li:1` and
`nfpr=1` were used to preserve exact spelling for finalists. Phralio browser
queries reviewed separately: exact name, `app`, `software`, and `reader`.
`reading` results were also reviewed through the search connector. A combined
query was exploratory only, not a substitute for the individual checks.

### Phralio: observed results

- **General web:** a personal Instagram handle and incidental/OCR text in old
  documents. No observed product claiming the name. Exact `reader` query returned
  no documents. `app` and `software` returned incidental archive/Scribd text.
- **Apple:** US software search returned zero results for Phralio. Searches for
  Fralio and Phraleo returned unrelated near matches, recorded in evidence.
  Storefront scope is US, not a worldwide store-name reservation check.
- **Google Play:** live US English search explicitly returned “No results for
  Phralio”. Phraleo likewise returned none. Fralio returned fuzzy suggestions
  including Frasio, Daylio, Mylio and Frameo; none was an exact Phralio reader.
- **GitHub:** repository-name search and user/organization search returned zero
  exact Phralio results. Fralio has personal accounts. These checks do not inspect
  every file or every private repository.
- **Packages:** npm returned zero Phralio search results; pub.dev returned fuzzy
  `mineral_ioc` / `flutter_ali_oauth` matches, not an exact package. The APIs can
  use fuzzy matching; search totals are not exact-name counts.
- **Language:** public results did not reveal a problematic meaning. This is not
  a multilingual linguistic clearance. English pronunciation has an F/Ph spelling
  tradeoff; no unsupported claim of universal ease is made.

### Domains

[Verisign .com RDAP](https://rdap.verisign.com/com/v1/domain/phralio.com) and
[Google .app RDAP](https://pubapi.registry.google/rdap/domain/phralio.app) returned
HTTP 404 / no record. DNS/HTTPS lookups for `phralio.com`, `phralio.app`, and
`phralio.io` did not resolve. The attempted `.io` RDAP service itself did not
resolve, so **.io registration status is unknown**. No active exact-name site was
observed. Registrar availability, premium pricing and registrability are not
verified; nothing was purchased. Do not embed an unowned domain into release
bundle identifiers or claim it in store copy.

### Preliminary trademark screening

[TMview](https://www.tmdn.org/tmview/) was searched in the public UI with all
statuses included and no territory/category exclusion:

- `Phralio` (contains): **No rows found**.
- `Fralio` (phonetic variant): four records: FRALIO registered in the US, class 18;
  two Chinese composite FRALIO marks, classes 18 and 25; Nefralio, EUIPO,
  classes 5, 10, 42, status Ended. The visible classes/statuses do not establish a
  current reading-software collision. Similarity and scope still require counsel.
- `Phraleo` (phonetic variant): **No rows found**.

The [WIPO database](https://branddb.wipo.int/) was blocked by the browser client;
it was not searched successfully. USPTO records above were surfaced through
TMview, not an independent exhaustive USPTO search. TMview itself states that it
is not an official register. No trademark registration or legal guarantee is
claimed. The class 18 FRALIO mark is expressly retained here for formal review,
not concealed behind an “unused name” claim.

## Repository transition

Renamed the existing repositories in place to `OmegaSkiller/phralio` (public)
and `OmegaSkiller/phralio-pro` (private), preserving their original commit
histories. Origin URLs, local checkout names and descriptions were updated.
Both retain `main`; Issues are disabled. Live GitHub API verification confirmed
the names and visibility on 25 September 2026. No repository was recreated. Keep the workspace parent name
unchanged to preserve the active task's working directory. Production bundle IDs
remain a release-configuration decision; brand and engine identities are separate.
