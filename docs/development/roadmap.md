# Milestone boundaries

Phase 0: selected Phralio after preliminary public research; renamed GitHub
repositories and local checkouts preserving initial history. Legal clearance is
not complete and no domains have been purchased.

Phase 1: offline paste/sample library, SQLite, adaptive native UI, RSVP timing,
focal positioning, settings, original identity, tests and CI source. See
`validation.md` for actual runs and their limits.

Library/appearance milestone: TXT and DRM-free EPUB ingestion, recent/starred
library, whole-book word positions, persisted themes, Lucide icons and restrained
Flutter glass controls. See `library-and-appearance.md`.

Rich-reading milestone: Markdown and public HTTPS article imports, bounded
supported images, EPUB/Markdown heading navigation, bookmarks, clipboard reading,
four primary tabs and tap-to-focus playback with paused word browsing.

Phase 2 remaining: conventional reflow reader, deeper
accessibility and performance profiling.

Phase 3: private PDF reflow prototype, scan detection, premium presentation and
commercial entitlements. No PDF processing is implemented in the current app.

Phase 4: physical devices, manual assistive-technology audits, production signing,
store assets/review, payment integration and release hardening. Legal owner,
private security contact and final identifiers require owner review before release.
Photo/screenshot OCR is deliberately deferred.
